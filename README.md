Dev Tools 🚀

Una suite de herramientas y utilidades web todo en uno, moderna y ultrarrápida, diseñada específicamente para desarrolladores y testers. Funciona 100% en el lado del cliente (client-side), garantizando velocidad, privacidad y cero dependencias externas.
✨ Características Principales

    JSON Formatter & Minifier: Valida, formatea y compacta estructuras JSON al instante.

    Suite de Cifrado y Matemáticas: Herramientas para codificación/decodificación Base64, Hexadecimal, Binario, Cifrado César (ROT13) y generación/cifrado asimétrico con RSA (1024-bit).

    Conversor y Codificador URL: Codifica y decodifica parámetros y URIs de forma segura.

    Minificador HTML & CSS: Limpia y comprime código web eliminando espacios y comentarios innecesarios.

    Traductor de Sintaxis (Languages): Selector y estructura base para lenguajes como Visual Basic, C++, Java, Python y JavaScript.

    Live HTML Preview: Visor en vivo para renderizar código HTML, CSS y JS en tiempo real dentro de un entorno seguro (iframe).

    SQL Suite: Formateador, minificador y generador de plantillas estándar para consultas de bases de datos.

    QA / Mock Data Generator: Generador inteligente de datos de prueba dinámicos basados en moldes JSON personalizados.

    Utilidades Dev Utils: Generador de UUID v4 y marcas de tiempo Unix/ISO al instante.

⚙️ Configuración y Entorno

    Modo Oscuro / Claro: Alterna entre temas visuales adaptados para largas jornadas de programación.

    Ajuste de Línea (Word Wrap) y Zoom: Controla la visualización del código con tamaños de fuente ajustables.

    Atajos de Teclado Globales:

        Ctrl + Enter: Procesa la conversión automáticamente.

        Ctrl + Shift + C: Copia el resultado al portapapeles.

        Ctrl + Shift + X: Limpia todo el espacio de trabajo.

🛠️ Tecnologías Utilizadas

    HTML5 / JavaScript (ES6+)

    Tailwind CSS (para un diseño minimalista, moderno y responsivo tipo VS Code)

    JSEncrypt (para gestión de criptografía RSA)
